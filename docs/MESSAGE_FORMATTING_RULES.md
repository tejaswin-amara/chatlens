# ChatLens Universal Message Formatting Rules & Standards

Version: 1.0.0  
Status: Active  

This document specifies the formatting contract, visual hierarchy, and styling rules enforced across all outbound messages generated by the ChatLens Enterprise PA Telegram bot.

---

## 1. The 4-Part Message Anatomy

Every response delivered by ChatLens to Telegram follows this four-part structure:

1. **Header Block**:
   - Primary Emoji + Bold Command Title (e.g., `⏰ **Upcoming Deadlines & Academic Intel**`).
   - Contextual subtitle in italics (e.g., `📅 *Sunday, 25 Oct 2026*` or `🕒 *Term T04 • Section S-10*`).
2. **Body & Card Blocks**:
   - Top-level entities prefixed with a bullet (`•`) and bold title.
   - Child details nested using the tree connector: `  └ 📄 **Sub-Item Title**`.
   - Grandchild details indented three spaces: `     • Key: Value`.
3. **Badges & Visual Status**:
   - Semantic color chips indicating state (🔴 Overdue / Danger, 🟡 Warning / Borderline / In Progress, 🟢 Safe / Success, ℹ️ Notice).
4. **Footer & Navigation**:
   - Helpful guidance in italics: `💡 *Tip: ...*`.
   - 2x2 inline keyboard grid for quick navigation.

## 2. Core Operational Rules

### [R-UI-1] No Raw Technical Jargon
- Never display internal database keys, SQL states, raw flags, or `(Status: PENDING)`.
- Replace technical states with executive human badges:
  - Overdue: `⚠️ Overdue (Due: DD Mon)`
  - Today: `🚨 Due Today!`
  - Future: `⏳ Due in X days (DD Mon)`
  - Undated: `📌 Action Item`

### [R-UI-2] Semantic Emoji Contract
Use emojis strictly according to their domain meaning:
- 📅 **Schedule & Dates**: `/today`, `/tomorrow`, `/timetable`
- ⏰ **Deadlines & Urgent Notices**: `/deadlines`, reminders
- 📊 **Attendance & Analytics**: `/attendance`, `/bunk`, `/margins`
- 🟢 **System Health & Online Status**: `/status`
- 🧠 **Machine Learning** (`25SC2107E`)
- 💻 **Data Structures & Algorithms** (`25CS2103E`)
- ⚙️ **Operating Systems & Systems Programming** (`25CS2104E`)
- 📡 **Embedded System Design & IoT** (`25EC2206E`)
- 🗄️ **Database Systems Engineering** (`25CS1302E`)
- 🌐 **Japanese Language Proficiency** (`25FL2112E`)
- 🏛️ **University Milestones**: Institutional academic calendar

### [R-UI-3] Link Sanitization & Markdown Safety
- Raw URLs must never be printed bare in the text.
- Automatically wrap URLs into named chips:
  - Google Drive: `🔗 [Google Drive Folder](url)`
  - Google Forms: `🔗 [Google Form](url)`
  - CodeTantra: `🔗 [CodeTantra Portal](url)`
  - Generic: `🔗 [Submission Link](url)`
- All markdown tokens (`*`, `` ` ``, `[`, `]`) must be balanced to prevent Telegram API 400 Bad Request errors.

### [R-UI-4] Course Grouping & Semantic Deduplication
- Multiple fragmentary messages regarding the same assignment or topic (e.g. MOOCS certificate notices) must be merged into a single consolidated card.
- Deduplicate instructions, extract the primary link, and assign course code/emoji context.

### [R-UI-5] Consistent Tree Connectors
- Use `└ ` for second-level hierarchies.
- Ensure consistent indentation:
  ```text
  • 🧠 **Course Name**
    └ 📄 **Assignment Title**
       • **Status**: ⚠️ Overdue
       • **Portal**: 🔗 [Link](url)
       • **Notes**: Guidance text
  ```

### [R-UI-6] Hierarchical LTPS Attendance Grouping
- All attendance cards must group instructional components (Lecture, Tutorial, Practical, Skilling) under their canonical course header.
- Multi-component cards must display component percentages with visual bars, safe bunks ($B_{85}, B_{75}$), and classes needed for recovery.
- If required recovery classes exceed remaining term classes ($m_{75} > R$), display hard detention warning: `🚨 DETENTION LOCKOUT`.
  ```text
  📊 **Live Academic Attendance & Safe Bunk Margins**
  🕒 *Term T05 • Updated: 14 Nov 2026, 20:15 IST*

  • 🧠 **GENAI** (`24CS2105A`) — **90.48%** 🟢 Safe
    ├ 📘 **Lecture**: 88.89% (16/18 hrs) `[████████░░]` 🟢 +0 safe
    └ 💻 **Practical**: 91.67% (22/24 hrs) `[█████████░]` 🟢 +2 safe
  ```

### [R-UI-7] Grounded RAG Citations & Zero Speculation
- Conversational answers to natural language questions must cite their authoritative source in square brackets:
  - Chat Source: `[Chat: <Channel/Group Name>, <Date/Time>]`
  - Document Source: `[Doc: <Filename>]`
- If information is absent from indexed chats or documents, respond strictly with: `"Not found in your chats/documents."` Never speculate or invent room numbers, dates, or faculty names.

### [R-UI-8] Timetable T05 Schedule & Period 6 Invariant
- Timetable displays must map official periods P1 (08:10) through P11 (18:00).
- Period 6 (`12:45–13:45`) is strictly reserved for the campus lunch break and must never be rendered as an academic lecture slot.
