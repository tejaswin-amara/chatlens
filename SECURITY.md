# 🛡️ Security Policy

We take the security and privacy of your chat data seriously. Because ChatLens is designed to index and analyze highly private messaging archives, we ask that you follow this policy to report any potential security concerns.

---

## Scope

This policy covers the maintained code on the default branch: the SPARK daemon (`src/`), ChatLens backend and frontend (`chatlens-v2/`), CI workflows, and deployment configuration. No separate legacy Flask or CLI application is maintained in this repository. Older commits and third-party forks may not receive fixes.

---

## 📥 Reporting a Vulnerability

> [!CAUTION]
> **Do not open public GitHub issues for security vulnerabilities.** Publicly disclosing vulnerabilities can expose users' private chat databases to risk.

Please report security issues privately to the maintainer:

*   **Email**: tejaswin-amara@users.noreply.github.com

To help us triage and resolve the issue quickly, please include:
1.  **Vulnerability Description**: Details of the issue and its potential impact.
2.  **Reproduction Steps**: Step-by-step instructions or a proof-of-concept script.
3.  **Environment Details**: The commit hash, OS, and platform version where the issue was found.

### ⏱️ Our Commitment
*   We will acknowledge your report within **48 hours**.
*   We will keep you updated as we work on a fix.
*   Once fixed, we will publish a patch release and credit your contribution (if desired).
