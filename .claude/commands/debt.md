# Technical Debt Command (`/debt`)

Harvest, inspect, and report deliberate technical shortcuts and deferrals:

1. **Scan**: Run `uv run python scripts/harvest_debt.py`.
2. **Review the local report**: Inspect `scratch/PONYTAIL-DEBT.md`, generated by the scan and ignored by Git. Do not commit this generated report.
3. **Assess risk**: Flag entries with missing upgrade triggers (`no-trigger`) and any shortcut whose documented ceiling has been reached.
4. **Report**: Summarize the total debt markers, markers missing triggers, and immediate remediation actions.
